# Mr Lifter

The code for Mr Lifter, a Hexy Hustle robot that runs on a goosebrain.

- **CAD:** [Onshape](https://cad.onshape.com/documents/1afa10c03c4be7ca0758a8e4/w/a1ca86cf551e01f9ed43cd05/e/2bc076201d51fad4b178a670)
- **Code:** [Code/Code.ino](Code/Code.ino). To build it, install the goosebrain board by following the [Loosey Goosey Robotics Arduino instructions](https://github.com/looseygooseyrobotics/arduino#readme).
